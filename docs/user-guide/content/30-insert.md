### 文字を直す

::: steps
1. 既存の文字を直す場合は、キャンバス上の文字をクリックします。新しく置く場合は上の **テキスト** を押します。
2. 右側の **テキスト** 欄に内容を入力します。
3. 書体、文字サイズ、太字、揃え方、文字色、背景色を調整します。
4. 幅と高さを数値で調整するか、キャンバス上の枠をドラッグします。
:::

### 画像を追加・差し替える

::: steps
1. 新しい画像は上の **画像** を押します。
2. Windowsの選択画面でPNG、JPEG、GIF、WebP、SVGのいずれかを選びます。
3. 追加された画像を移動・拡大縮小します。
4. 既存画像を変える場合は画像を選び、右側の **画像を差し替える** を押します。
5. 必要なら **全体を表示**、**枠に合わせて切り抜く**、**枠いっぱいに伸ばす** を選びます。
:::

追加画像はHTMLへ埋め込まれず、HTMLと同じ場所の `<HTML名>.assets/` にコピーされます。HTML本体が画像データで大きくなり続けることを防ぐためです。

::: notice
文字編集画面は実画面で確認済みです。画像の保存先・再利用・未参照画像回収は自動テスト済みですが、Windows標準の画像選択画面は今回の自動撮影には含めていません。
:::
