HTML Slide Studioは、AIなどで作った静的HTMLスライドを最後に人が整えて発表するためのWindowsアプリです。独自の作業形式を覚える必要はありません。

- 文字、色、書体、位置、大きさを直す
- 文字と画像を追加・差し替える
- スライドを追加・複製・並べ替える
- 発表者ノートと発表前チェックを使う
- 開いたHTMLへ上書き保存し、そのまま発表する

::: notice
**保存は上書きです。** 元版も残したい場合は、アプリで開く前にHTMLと関連画像フォルダを自分でコピーしてください。
:::
