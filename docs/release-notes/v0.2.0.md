# HTML Slide Studio v0.2.0

HTML Slide Studio v0.2.0は、発表前checkとWindows配布方法を改善するReleaseです。

## 主な変更

- 表示中のslideを変えずに全slideをまとめて検査し、指摘から対象slideと要素へ移動できるようになりました。
- 正常な文字の折返しをclippingと誤判定せず、実際に隠れる／scrollを要する文字を検出します。
- Windows ARM64／x64それぞれに、通常インストーラー、portable EXE、展開型ZIPを用意します。
- インストーラー版は展開済みpayloadを起動するため、起動ごとに自己展開するportable EXEより通常利用に適しています。
- 入力HTMLの危険なURL方式と埋め込みHTMLを読み込み時に除去し、編集内容の復元用dataを入力HTMLから分離しました。

## ダウンロード

PCの「設定 → システム → バージョン情報」でシステムの種類を確認してください。

- Snapdragon搭載Windows PC: `HTML Slide Studio Setup 0.2.0-arm64.exe`
- Intel／AMD搭載Windows PC: `HTML Slide Studio Setup 0.2.0-x64.exe`
- インストールできない場合の予備経路: architectureに合うportable EXEまたはZIP

各fileのSHA-256は`SHA256SUMS.txt`で確認できます。

## 確認範囲

- Windows ARM64／x64のnative GitHub Actions runnerで、source境界、user guide、unit test、実Electron E2E、package verifierを実行します。
- Windows 11 ARM64ではinstaller、shortcut、起動、同梱デモを実機確認済みです。
- x64版はnative x64 CIで自動確認しますが、ownerのnative x64実機受入が終わるまでは暫定対応です。
- 物理2画面の配置とcustom NTFS ACLの完全保持は環境依存の受入項目です。

## 注意

- 対応環境はWindows 10以降の64-bit ARM64／x64です。x86、macOS、Linux向け配布物はありません。
- コード署名をしていないため、Windowsの警告が表示される場合があります。警告を避ける目的でセキュリティ機能を無効化せず、GitHubの配布元とSHA-256を確認してください。
- 保存は開いたHTMLへの上書きです。元版も残す場合は、開く前にHTML一式をコピーしてください。
