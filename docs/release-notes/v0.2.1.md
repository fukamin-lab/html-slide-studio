# HTML Slide Studio v0.2.1

HTML Slide Studio v0.2.1は、Windows配布版の基盤を更新するpatch Releaseです。アプリの操作方法と保存形式に変更はありません。

## 主な変更

- Electronを42.9.1へ更新し、42系列の最新patchに含まれる安定性修正を反映しました。
- Lucide Reactを0.577.0へ更新し、画面内iconと第三者license表示を公式packageへ同期しました。
- 更新後の実画面で、開始画面、編集、slide操作、text編集、発表前check、保存、発表画面のiconと配置を再確認しました。

## ダウンロード

PCの「設定 → システム → バージョン情報」でシステムの種類を確認してください。

- Snapdragon搭載Windows PC: `HTML.Slide.Studio.Setup.0.2.1-arm64.exe`
- Intel／AMD搭載Windows PC: `HTML.Slide.Studio.Setup.0.2.1-x64.exe`
- インストールできない場合の予備経路: architectureに合うportable EXEまたはZIP

各fileのSHA-256は`SHA256SUMS.txt`で確認できます。

## 確認範囲

- Windows ARM64／x64のnative GitHub Actions runnerで、source境界、user guide、unit test、実Electron E2E、package verifierを実行します。
- 公開済みv0.2.1成果物を再downloadしてSHA-256を照合し、Windows 11 ARM64物理端末へ上書きinstallしました。installer内25製品fileとのhash不一致0、registry 0.2.1、Desktop／Start Menu shortcut、開始画面を確認しています。
- Windows 11 native x64物理端末では、v0.2.1 x64 installer、PE `0x8664`、registry 0.2.1、両shortcut、同梱8枚デモ、発表前check 0件、Presenter、未保存Cancel／Discardを確認しています。
- custom NTFS ACLの完全保持は環境依存の受入項目です。

## 注意

- 対応環境はWindows 10以降の64-bit ARM64／x64です。x86、macOS、Linux向け配布物はありません。
- コード署名をしていないため、Windowsの警告が表示される場合があります。警告を避ける目的でセキュリティ機能を無効化せず、GitHubの配布元とSHA-256を確認してください。
- 保存は開いたHTMLへの上書きです。元版も残す場合は、開く前にHTML一式をコピーしてください。
